# T016 — Production Quality Monitoring & Anomaly Detection

This directory contains monitoring specifications, architecture, threshold configurations, metrics schemas, alert rules, daily report templates, and results for T016.

## Files
- `README.md`: Directory sitemap
- `architecture.md`: Self-monitoring system architecture and component pipeline diagram
- `thresholds.md`: Complete list of WARNING / ERROR / CRITICAL threshold rules
- `metrics-schema.md`: Monitoring SQLite database (`monitoring.db`) schema definitions
- `alert-rules.md`: Alert deduplication, recovery (RESOLVED), and cooldown rules
- `daily-report.md`: Daily quality summary report template
- `results.md`: T016 final validation report and Fault Injection simulation results
- `regression.md`: Safety regression and unit test verification report
