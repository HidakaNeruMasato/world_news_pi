# T026 ユーザビリティタスク仕様書 (Task Sheet UJ-001 〜 UJ-016)

## タスク一覧と定型指示文

本仕様書は、全テスター (`T01`, `T02`, `T03`) に統一して実施する 16 の評価タスクの定義です。

---

### UJ-001: 初見探索 (First Exploration)
- **タスク文**: 「まず、このサイトを自由に30秒ほど見てみてください。」
- **目的**: 初見で最初に注目する領域、地図とリストの認知順番、初回アクションを観察。
- **成功条件**: 自由に画面を閲覧・操作し、印象を述べられること。

### UJ-002: 世界のニュースを探す (World News Search) 【Critical Task】
- **タスク文**: 「今、世界でどんなニュースが起きているのか、いくつか見てみてください。」
- **目的**: ニュースイベント詳細 (Event Detail) へ自力で到達できるか検証。
- **成功条件**: 最低1件の Event Detail を開いて内容を確認できること。

### UJ-003: アフリカのニュースを探す (Region Filter) 【Critical Task】
- **タスク文**: 「アフリカで起きているニュースを探してみてください。」
- **目的**: Region Filter の発見性と操作性を検証。
- **成功条件**: アフリカのイベントを 1 件以上表示・選択できること。

### UJ-004: 特定国へ絞り込む (Country Filter) 【Critical Task】
- **タスク文**: 「アフリカの中から、ナイジェリアのニュースを探してみてください。」
- **目的**: Region → Country の2段階フィルタリング構造の直感性を検証。
- **成功条件**: ナイジェリアのニュースへ正しく絞り込めること。

### UJ-005: Map → List → Detail (地図起点操作) 【Critical Task】
- **タスク文**: 「地図から気になるニュースを1つ選んで、詳しく見てください。」
- **目的**: 地図上のマーカー/クラスタから詳細パネルへの連動性を検証。
- **成功条件**: 地図ピンのタップ/クリックから Event Detail へ到達。
- **Critical Failure**: マーカーが選択できない、Detail が開かない。

### UJ-006: List → Map → Detail (リスト起点操作)
- **タスク文**: 「ニュース一覧から気になるニュースを選び、その場所を地図で確認してください。」
- **目的**: リスト選択時の地図自動パン・ズーム連動の理解度を検証。
- **成功条件**: リストから選択し、地図上の位置を正しく認識できること。

### UJ-007: 複数記事イベントの比較 (Multi-Article Event) 【Critical Task】
- **タスク文**: 「このニュースについて、他の報道メディアの記事も見てみてください。」
- **目的**: 単一イベントに複数媒体が紐付く構造と Source Badge の発見性を検証。
- **成功条件**: 同一 Event 内の別メディア記事カードに到達し比較できること。

### UJ-008: 元記事への到達 (Original Article Link)
- **タスク文**: 「このニュースの元記事を読んでみてください。」
- **目的**: 元記事リンク (`[ 元記事を読む ↗ ]`) の視認性と直感性を検証。
- **成功条件**: 元記事の外部 URL リンクを正しくクリック/開けること。

### UJ-009: URL 利用不可ケースの対応 (Unavailable URL State) 【Critical Task】
- **タスク文**: 「このニュースについて、元の記事を読んでみてください。」 (※ URL 障害記事を提示、説明は行わない)
- **目的**: リンク切れ時にユーザーが行き止まりにならず、Article Preview や代替記事へ進めるか検証。
- **成功条件**: リンク障害メッセージを理解し、プレビューまたは代替記事を活用して情報を得られること。

### UJ-010: キーワード検索 (Search)
- **タスク文**: 「興味のあるキーワードでニュースを検索してみてください。」
- **目的**: 検索バーの発見性と検索結果表示のわかりやすさを検証。
- **成功条件**: 検索窓に入力し該当ニュースを表示できること。

### UJ-011: リスト並び替え (Sort)
- **タスク文**: 「ニュース一覧を、自分が見やすい順番に並べ替えてみてください。」
- **目的**: Sort UI (発生順/最新順/信頼度順) の発見性を検証。
- **成功条件**: リストの並び替え操作を実行できること。

### UJ-012: 複合条件フィルター (Combined Filter) 【Critical Task】
- **タスク文**: 「アジア地域の中から特定の国を選び、さらに『政治・社会』カテゴリも絞ってみてください。」
- **目的**: Region + Country + Category の複合条件適用時の動作理解を検証。
- **成功条件**: 複合条件が適用され、表示が正しく絞り込まれること。
- **Critical Failure**: フィルター結果と地図/リストの表示内容が不一致になること。

### UJ-013: フィルターリセット (Reset)
- **タスク文**: 「複数の条件を付けた後、最初の状態に戻してください。」
- **目的**: Reset ボタンの発見性と全クリア挙動の理解度を検証。
- **成功条件**: 自力で Reset を発見し初期全表示に戻せること。

### UJ-014: 高密度地域の閲覧 (High Density Cluster)
- **タスク文**: 「ニュースが密集している地域（ヨーロッパ等）から、気になるニュースを1つ選んでください。」
- **目的**: マーカークラスタの展開挙動と高密度地域の操作性を検証。
- **成功条件**: クラスタを展開し個別イベントを選択できること。

### UJ-015: モバイル探索フロー (Mobile Exploration) 【Critical Task】
- **タスク文**: 「スマートフォンで、世界のニュースをいくつか探してみてください。」
- **目的**: スマホ画面での Bottom Sheet, Map, List の行き来の自然さを検証。
- **成功条件**: スマホで Map → List → Detail フローを完遂できること。

### UJ-016: モバイル詳細閲覧と戻り (Mobile Detail & Navigation) 【Critical Task】
- **タスク文**: 「このニュースについて詳しく見て、元の記事を読めるところまで進んでください。」
- **目的**: スマホの Bottom Sheet 展開、全画面詳細、閉じるボタンの適合性を検証。
- **成功条件**: 詳細パネルから元記事・代替記事へ進み、閉じて地図へ戻れること。
- **Critical Failure**: 詳細が画面を占有して地図/リストへ戻れない。
