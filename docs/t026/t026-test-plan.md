# T026 友人向け外部ユーザーテスト 計画書 (Usability Test Plan)

## 1. テストの目的

本テストは、T025/T025-1 で構築および外部セキュリティ検証をクリアした **World News Map 外部ユーザーテスト環境 (Friend Test Environment)** を用い、開発者ではない一般ユーザー 3 名を対象として初見ユーザビリティテストを実施するものです。

主目的は新機能の技術検証ではなく、**「初めて本サイトを見る一般ユーザーが、事前説明や開発者の操作誘導なしで、世界のニュースを地図やフィルターを通じて自然に探索・理解・活用できるか」** を客観的に測定・評価することです。

---

## 2. 実験環境とセキュリティ分離

* **テスト環境**: GitHub Pages (`https://<user>.github.io/world-news-map/`) + Read-Only Friend Test API (`worldnews_test.db`)
* **本番環境への非接続**: Production Pi3/Pi4/SQLite (`worldnews.db`)/LLM には一切接続しません。
* **テスト同一条件の維持**: テスターごとのコード改修、プロンプト変更、データ変更、UI 調整を完全禁止し、全参加者が同一条件で評価します。

---

## 3. テスター（参加者）プロフィール

個人情報保護のため、匿名 ID (`T01`, `T02`, `T03`) で管理します。全員「システム開発未経験」「World News Map を初めて見る」「事前仕様説明なし」の条件を満たします。

| テスター ID | 主な使用デバイス | OS / ブラウザ | 参加者背景概要 |
|---|---|---|---|
| **T01** | PC (デスクトップ) | Windows 11 / Chrome | 日常的にニュースサイトや Google マップを閲覧する一般ユーザー |
| **T02** | スマートフォン | iOS 17 / Safari | スマホでの情報収集が中心の一般ユーザー |
| **T03** | PC + スマートフォン | macOS / Edge, Android / Chrome | PC とスマホの両方を使い分ける一般ユーザー |

---

## 4. 最重要進行方針（無誘導原則）

1. **操作方法を教えない**: 「ここをクリック」「Region Filter を使う」「このボタンが元記事」等の誘導を禁止。
2. **質問への対応**: 「どうしたらできると思いますか？」「今何をしようとしていますか？」と問い返し、支援レベル（Help Level 1〜3）を記録。
3. **エラーは UX の結果**: ユーザーの迷いや間違いはユーザーの責任ではなく、サイト UI の設計課題として正確に記録。

---

## 5. 評価目標値 (PASS Criteria)

| 指標 | 定義 | 目標値 |
|---|---|---|
| **Overall Task Success Rate** | 成功タスク数 / 全タスク数 × 100 | **>= 95%** |
| **Critical Task Success Rate** | 重要タスク (UJ-002, 003, 004, 005, 007, 009, 012, 015, 016) 達成率 | **100%** |
| **P0 致命的課題数** | サービスの目的理解不能・主要機能利用不可の件数 | **0 件** |
| **P1 重大課題数** | 主要タスク達成への重大な障害件数 | **0 件** |
| **Overall Satisfaction** | 5段階アンケート満足度平均 | **>= 4.0 / 5.0** |
| **初見理解率 (Initial Understanding)** | 画面を見ただけで「世界のニュース地図」と理解できた割合 | **> 50%** |
