# World News Map — T020 Human Review Guide (評価ガイドライン)

本ドキュメントは、World News Map におけるニュースイベント価値評価（T020 Human Review）の評価基準・点数定義・評価手順を定義したガイドラインです。

---

## 1. 評価概要

各サンプルイベントについて、以下の 7 指標（1〜5 点）およびオプションコメントを評価・記入します。

---

## 2. 各評価指標の点数定義

### 2.1 Interesting (見たい・興味深いか？)
* **1点**: ほぼ興味なし（ローカルな行政手続き、微小な宣伝記事）
* **2点**: あまり興味なし
* **3点**: 普通（一般的な国内ニュース）
* **4点**: 興味深い（国際的に注視される出来事、主要事件）
* **5点**: 非常に興味深い（歴史的大事件、緊急性の高いニュース）

### 2.2 Importance (世界のニュースとして重要か？)
* **1点**: ほぼ重要ではない
* **2点**: 重要度が低い
* **3点**: 中程度（一国レベルで一定の影響があるニュース）
* **4点**: 重要（国家レベルの政策変更、大規模事故・自然災害）
* **5点**: 非常に重要（戦争・紛争発端、大規模災害、グローバル経済変動）

### 2.3 Global Relevance (現地以外の人にも意味があるか？)
* **1点**: ほぼ現地・当事者のみ（市町村レベルの地域イベント）
* **2点**: 周辺地域・国内のみ
* **3点**: 一定の国際的関心あり
* **4点**: 国際的に重要（他国の外交・安全保障・貿易に影響）
* **5点**: 全世界的に意味がある（全地球規模の影響）

### 2.4 Map Value (地図上に表示する価値があるか？)
* **1点**: 地図に表示する意味がほぼない（抽象的な論説、一般的な意見表明）
* **2点**: あまり相性が良くない
* **3点**: どちらともいえない
* **4点**: 地図表示と相性が良い（地理的位置が意味を持つニュース）
* **5点**: 地図だからこそ価値が高い（地震、台風、国境紛争、軍事移動、国際会議、抗議活動、現地事故）

### 2.5 Duplicate / Redundancy (重複感・冗長性)
* **1点**: 重複ほぼなし（単一の明確な出来事）
* **2点**: 少ない
* **3点**: 普通
* **4点**: 多い（ほぼ同一内容が別イベントとして重複表示されている）
* **5点**: 非常に多い（過度な重複）

### 2.6 Local Noise (ローカルすぎるニュースか？)
* **1点**: 世界ニュースとして適切（ノイズ感ゼロ）
* **2点**: 少しローカル
* **3点**: 中程度
* **4点**: かなりローカル（世界地図には不適切）
* **5点**: ほぼ完全なローカル・身内ニュース

### 2.7 Would View On Map (最重要指標: 地図上で見たいか？)
* **1点**: 見たくない
* **2点**: あまり見たくない
* **3点**: どちらでもない
* **4点**: 見たい
* **5点**: 必ず見たい

## 3. レビュー作業手順

1. [docs/t020/review.html](file:///d:/myproject/world_news_pi/world-news-map-spec-v0.2/docs/t020/review.html) をブラウザで開くか、[docs/t020/review.csv](file:///d:/myproject/world_news_pi/world-news-map-spec-v0.2/docs/t020/review.csv) または [docs/t020/dataset.json](file:///d:/myproject/world_news_pi/world-news-map-spec-v0.2/docs/t020/dataset.json) を確認します。
2. イベントのタイトル、サマリー、発生国、ソースメディア、関連記事の URL・内容を確認します。
3. 上記定義に従って `interesting`, `importance`, `global_relevance`, `map_value`, `duplicate_redundancy`, `local_noise`, `would_view_on_map` の 7 指標（1〜5）を記入します。
4. 必要に応じてコメント欄に理由・補足を記述します。
