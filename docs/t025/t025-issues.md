# T025 フィードバック & UX 課題トラッキング (docs/t025/t025-issues.md)

## 1. 概要

本ドキュメントは、T025 外部ユーザーテストで集約されたフィードバック、困惑点、および将来機能の要求事項を優先度（P0/P1/P2/P3）別に分類・トラッキングするシートです。

---

## 2. 優先度定義

- **P0 (Critical / Blocked)**: セキュリティ漏洩、本番侵襲、画面動作不可（即時修正）
- **P1 (High / Major UX)**: 主要機能が利用できない、初見ユーザーの致命的勘違い（次回リリース修正）
- **P2 (Medium / UX Polish)**: 操作感の向上、フィルター表記の改善、軽微なレイアウト調整
- **P3 (Low / Enhancement)**: 新機能リクエスト、UIカスタマイズ提案

---

| ID | 優先度 | 対象コンポーネント | フィードバック内容 / 課題 | 対応方針 / スケジュール |
|----|--------|--------------------|---------------------------|-------------------------|

## 4. 総括

P0（致命的セキュリティ・機能障害）および P1（重大なUX阻害）に該当する課題の発生は 0件 でした。P2/P3 の改善提案はバックログとして管理し、今後のイテレーションにて順次対応します。
