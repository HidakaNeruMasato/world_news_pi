# T025 外部ユーザーテスト計画書 (docs/t025/t025-test-plan.md)

## 1. テストの目的

2〜3名の友人テスターに対し、口頭説明を最小限に抑えた状態で World News Map を実際に利用してもらい、以下の初見 UX および機能理解度を検証します。

1. 地図からの直感的なニュース探索可能性
2. フィルター機能 (Region / Country / Category) の理解しやすさ
3. イベント詳細パネル (Event Detail) および複数媒体比較 (Multi-Article) の利便性
4. T024 URL 障害表示 (ACTIVE, REDIRECTED, NOT_FOUND, GONE, BLOCKED) の適切さ
5. PC / スマートフォン両環境での操作性

---

## 2. 実施ルール (Observer Guideline)

- **最小限の説明**: テスト開始時は「世界のニュースを地図上から探せるサイトです。自由に使ってみてください」程度にとどめる。
- **操作の口出し禁止**: テスターが迷ってもすぐに解答や操作手順を教えない。何をしようとしてどこで詰まったかを観察・記録する。
- **個人情報の不収集**: テスターの氏名、メールアドレス、電話番号、GPS位置情報等は一切収集しない（匿名セッション ID のみ使用）。

---

## 3. 被験者向けテストタスク (Task 1 〜 6)

### Task 1
> **「気になったニュースを1つ見つけて選択してください。」**

### Task 2
> **「アフリカ地域のニュースだけを表示するように絞り込んでください。」**

### Task 3
> **「選択したニュースの詳しい内容（概要や発生日時）を確認してください。」**

### Task 4
> **「ニュースの元記事（ニュース発行元のWebサイト）を開いてみてください。」**

### Task 5
> **「同じニュースを報じている『別のニュース媒体の記事』があるか確認してください。」**

### Task 6
> **「スマートフォン（またはスマホサイズ画面）で同じ操作を一通り試してください。」**

---

## 4. 観察記録シート & 5段階評価項目

各タスクについて以下を記録します：
- **成否 (Success / Failure)**
- **所要時間 (Completion Time)**
- **誤操作・迷い回数 (Mistake Count)**
- **定性コメント・困惑点 (Confusion / Comment)**

### 5段階評価 (UX Rating)
1. 非常に分かりにくい / 2. 分かりにくい / 3. 普通 / 4. 分かりやすい / 5. 非常に分かりやすい

- **Map UI**
- **Filter UI**
- **Event Detail UI**
- **Article Preview / Original Link**
- **T024 URL Status Display**
- **Mobile UI (Bottom Sheet)**
- **総合満足度 (Overall)**

---

## 5. インタビュー質問項目 (Post-Test Questions)

1. 一番分かりやすかったところ・気に入ったところはどこですか？
2. 一番分かりにくかったところ・迷ったところはどこですか？
3. 「元記事を確認できません」などの表示を見たとき、どのような印象を受けましたか？
4. スマートフォンでの操作感はいかがでしたか？
5. 最後に**「このサイトは何をするサイトだと思いましたか？」**（自由回答）
