# Recommended Initial RSS Expansion Feeds (T019 Selected Sources)

This document specifies the **37 selected Tier A candidate RSS feeds** recommended for initial expansion of World News Map.

These sources were selected from 127 candidates based on:
1. **HTTP 200 & XML Parse Verification** (Tested live).
2. **High Update Volume** (Regular article updates).
3. **Geographic Diversity** (Filling gaps in South Asia, SE Asia, Africa, Latin America, Eastern Europe, Oceania).
4. **Reliability & Editorial Quality**.
