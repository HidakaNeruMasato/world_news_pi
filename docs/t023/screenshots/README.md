# T023 Production UX Screenshots & Visual Artifacts

This directory contains visual regression screenshots capturing the major UI/UX states validated during T023.

## Captured Screenshots Inventory

1. `desktop-global.png` - Desktop full screen global map view with Overview Strip in Header (120 active events).
2. `desktop-region-filter.png` - Cascading Region & Country dropdown filter applied (e.g. Africa -> Nigeria).
3. `desktop-cluster.png` - Marker clustering view at zoom level 3 showing `[N]` badges over Europe and Africa.
4. `desktop-event-detail.png` - Selected event card with map camera pan and EventDetailPanel open.
5. `desktop-multi-article.png` - Multi-article event showing `[N Articles]` badge and media sources list.
6. `mobile-map.png` - Mobile 390px viewport showing map as primary view with collapsed Bottom Sheet.
7. `mobile-bottom-sheet.png` - Mobile Bottom Sheet expanded to half and full view showing scrollable EventList.
8. `mobile-detail.png` - Mobile event detail panel view with back navigation button.
